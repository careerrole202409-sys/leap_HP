会社概要

Leapでは、提供する製品と同じように、組織のカルチャーや会社そのものもゼロから開発し、すべての企業が世界を舞台に飛躍できる社会を目指しています。

ミッション

すべての企業がグローバルに飛躍することをサポートする

Leapは「すべての企業がグローバルに飛躍することをサポートする」というミッションを掲げています。数字ばかりを追求した表面的な成長（Growth）ではなく、国境を越え、新たな市場で本質的な価値を届ける「飛躍（Leap）」をサポートすることが、私たちの使命です。

わたしたちのカルチャー

私たちは、最高の成果を最速でお客様に届けるために、3つのコアバリューを大切にしています。

責任

一人一人がお客様に対するアウトプットの質に全責任を持ち、プロフェッショナルとして完遂します。

集中

アウトプットを高めるために、最も重要なことだけにリソースを研ぎ澄まします。

スピード

集中することで、誰よりも最速で行動し、市場の変化を超えるスピードでアウトプットを出します。

沿革

2024年7月、東京大学在学中からDXを通じて社会に貢献することを目指していた従兄弟の二人、原と鶴岡によってLeapは創業されました。

原は、内閣府でのマクロ経済政策の経験から「日本企業のグローバルな飛躍こそが、日本経済再生の鍵である」と確信。一方、日立製作所で生成AIの研究開発に従事していた鶴岡は、AIの進化が言語や商習慣といった海外展開の壁を劇的に低くしていることを実感していました。

「今後10年以内に、世界中の企業がグローバルに事業を行うことが当たり前になる」

そう確信した二人は、テクノロジーと戦略で企業の挑戦を支えるため、横浜の地でLeapを設立しました。
