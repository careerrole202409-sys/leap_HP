よくあるご質問 (FAQ)

どの国のどのモールに対応していますか？
現在は、東南アジア・台湾向けのShopee、東南アジア向けのLazada、韓国向けのCoupang、欧米日向けのAmazonグローバルセリング、および日本国内向けの楽天に対応しています。
出品までどのくらいの期間がかかりますか？
必要情報をご入力いただいてから、通常2週間〜1ヶ月ほどでモールの開設および出品が完了します。すでに情報が揃っている場合はさらに短縮できる場合もあります。
英語や現地の言葉ができなくても大丈夫ですか？
はい、問題ありません。商品情報の翻訳や顧客対応のテンプレート化など、Leapが言語の壁をサポートする機能を提供しています。
料金体系について詳しく教えてください。
越境EC機能は有料プラン（Standard）以上でご利用いただけます。出品・連携したいモールの数に応じて、1モールあたり月額2万円（税抜）が発生します。
