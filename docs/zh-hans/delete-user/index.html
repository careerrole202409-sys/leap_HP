如何删除账户

制定于2025年10月28日

1

登录Leap

请通过以下网址登录Leap。

https://app.leap.site/top
2

进入个人中心

在页面顶部导航栏选择"我的页面"进入个人中心。

3

打开设置

点击右上角的"账户设置"按钮。

4

点击删除账户按钮

点击"删除账户"按钮。

5

确认删除

系统将弹出提示"您的所有信息将从Leap中永久删除，确定继续吗？"。请在输入框中输入"删除"二字，然后点击确定按钮。您的账户信息将在一周后从Leap中完全删除。

⚠️ 重要提示

账户删除一周后，所有数据将被永久删除且无法恢复。请在删除前备份您需要保留的数据。
