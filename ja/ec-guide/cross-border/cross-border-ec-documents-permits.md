## 【1分で解説！】越境ECに必要な書類と許可

越境ECで必要な書類や許可は、越境ECという売り方ではなく、「扱う商品」「送り先の国」「送り方」で決まります。確認することは、大きく次の4つです。

1. **商品を扱うための国内の許可**：中古品を仕入れて売るなら古物商許可、お酒を売るなら酒類販売業免許など
2. **輸出の許可**：外為法（外国為替及び外国貿易法）の輸出規制や、植物防疫法・家畜伝染病予防法などの「他法令」に当てはまらないか
3. **発送の書類**：郵便なら税関告知書、20万円を超える場合は輸出申告と仕入書（インボイス）など
4. **販売サイトの表示と法律**：特定商取引法の表示、販売国の消費者保護や個人情報のルール、商標

本記事では、越境ECを始める中小企業の担当者向けに、この4つを税関・経済産業省・国税庁などの公開情報をもとに整理します。法律の当てはめは商品や取引の形で変わるため、判断が必要な部分は、記事の後半で紹介する相談先に確認してください。

## 越境ECに必要な書類・許可・法律の全体像

越境ECに必要な書類・許可・法律は、「始める」「仕入れて扱う」「送る」「売る」の4つの場面に分けると整理しやすくなります。

| 場面 | 主な書類・許可・法律 | 主な確認先 |
|---|---|---|
| 事業を始める | 開業届（個人事業主の場合） | 税務署 |
| 商品を仕入れて扱う | 古物商許可、酒類販売業免許など | 警察署、税務署など |
| 海外に送る | 外為法の輸出許可、他法令の許可・承認、税関告知書、輸出申告書、仕入書 | 経済産業省、各法令の主管省庁、税関、通関業者 |
| サイトで売る | 特定商取引法の表示、販売国の法律、商標 | 消費者庁の案内、弁護士、特許庁 |

国内でECを運営している会社なら、「始める」場面の準備はすでに済んでいることが多く、越境ECで新しく確認が必要になるのは、主に「送る」と「売る」の場面です。

## 越境ECを始めるときに必要な書類

個人事業主として越境ECを始める場合は、税務署に開業届（個人事業の開業・廃業等届出書）を出します。国税庁によると、開業届の提出期限は、事業を始めた日が属する年分の確定申告期限までです。

青色申告を選ぶ場合は、青色申告承認申請書も出します。提出期限は原則として青色申告をしようとする年の3月15日までで、その年の1月16日以後に新しく事業を始めた場合は、事業を始めた日から2か月以内です。

## 越境ECに許可は必要か

越境ECの許可が必要かどうかは、扱う商品で決まります。一般的な雑貨や衣類を新品で仕入れて販売する場合と、中古品やお酒を販売する場合とでは、必要な許可が異なります。

### 中古品を仕入れて販売するなら古物商許可

中古品を仕入れて販売する場合は、古物営業法にもとづく古物商許可が必要です。大阪府警察のQ&Aでは、自分で使っていた物や、自分で使うために買った未使用品を売るだけなら許可は不要で、転売するために古物を買う場合は許可が必要と説明されています。

警視庁の案内では、申請先は主たる営業所の所在地を管轄する警察署で、手数料は19,000円です（2026年11月時点）。

### お酒を販売するなら酒類販売業免許

お酒をインターネットで継続して販売する場合は、販売場ごとに、所在地を管轄する税務署長から酒類販売業免許を受ける必要があります。国税庁は、インターネットを利用した酒類の販売に必要な免許は、受発注の態様などにより個々に判断するとしています。

酒類販売業免許には、輸出される酒類を卸売できる「輸出入酒類卸売業免許」などの種類があります。海外の消費者に直接販売する場合にどの免許が必要になるかは販売方法によって変わるため、計画の段階で所轄の税務署に確認してください。

### 食品・化粧品などは国内と販売国の両方のルールを確認する

食品・化粧品・健康食品・医薬品などは、製造や販売のしかたによって国内で許可や届出が必要になる場合があり、販売国にも成分・表示・登録のルールがあります。国内のルールは保健所や都道府県の担当窓口、販売国のルールはジェトロ（日本貿易振興機構）の「輸出入に関する基本的な制度」で確認できます。ジェトロは、主要な約60の国・地域の輸出入制度をまとめています。

## 輸出に必要な許可：外為法と他法令

日本から商品を送るときは、その商品が輸出の許可や承認の対象でないかを確認します。対象かどうかは、商品の種類と送り先の国で決まります。

### 外為法の輸出規制（安全保障貿易管理）

外為法の輸出規制とは、武器や、兵器の開発などに使われるおそれのある貨物・技術の輸出に、経済産業大臣の許可を求める制度です。経済産業省の案内では、規制には次の2つがあります。

- **リスト規制**：輸出貿易管理令で定められた品目に当たる貨物は、例外規定を使えない限り、送り先や用途にかかわらず許可が必要です
- **キャッチオール規制**：リスト規制に当たらない貨物でも、大量破壊兵器や通常兵器の開発などに使われるおそれがある場合は許可が必要です（輸出管理を厳格に行っている一部の国向けは対象外）

商品がリスト規制に当たるかどうかを調べることを「該非判定」といいます。経済産業省は該非判定を行わないため、輸出者が自分で行います。電子部品・機械・化学品などを扱う場合は、メーカーから該非判定書を取り寄せられるかも確認しておきます。

### 他法令の許可・承認

他法令とは、関税関係以外の法律のうち、輸出や輸入に許可・承認などを定めたものです。税関によると、他法令の許可・承認が必要な貨物は、それを受けて税関に証明しなければ輸出が許可されません。税関が示す主な他法令は次のとおりです（令和8年4月現在）。

| 法令 | 主な品目 |
|---|---|
| 外為法（輸出貿易管理令） | 武器・化学兵器、麻薬、ワシントン条約該当物品、制裁対象の貨物など |
| 文化財保護法 | 重要文化財、重要美術品、天然記念物など |
| 鳥獣保護管理法 | 野生の鳥・獣とその加工品、鳥類の卵など |
| 家畜伝染病予防法 | 偶蹄類の動物、家きん、それらの肉・ソーセージ・ハムなど |
| 植物防疫法 | 植物（種子・果実などを含む）、有害植物、有害動物 |
| 狂犬病予防法 | 犬、猫、あらいぐま、きつね、スカンク |

税関は、他法令に当たるかどうかの問い合わせには答えられないとしており、各法令を担当する省庁に確認するよう案内しています。

## 発送に必要な書類

越境ECで商品を送るときの書類は、送り方と商品の価格で変わります。郵便で送る場合は、価格が20万円以下か、20万円を超えるかで手続きが分かれます。

### 郵便で送る場合：税関告知書と輸出申告

税関の案内では、郵便物の手続きは次のとおりです。

1. **20万円以下**：税関への輸出申告は不要です。日本郵便の国際郵便マイページサービスで税関告知書を作り、郵便物に貼って差し出します。税関検査で他法令の許可・承認が必要な品物が見つかった場合は、税関からはがきで手続きの案内が届きます。
2. **20万円超**：税関への輸出申告が必要です。仕入書などの書類をそろえ、日本郵便や通関業者に依頼するか、自分で申告します。

税関告知書の価格欄には、FOB価格（原則として、実際の決済金額）を書きます。

### 輸出申告に必要な書類

輸出申告では、輸出申告書に仕入書（インボイス）または仕入書に代わる書類を添えて税関長に出します。税関によると、場合によっては次の書類も必要です。

- 包装明細書（パッキングリスト）
- 他法令の許可・承認証など（他法令に当たる貨物の場合）
- 関税の軽減・免除などに関係する書類

国際宅配便を使う場合に用意する書類は、配送会社の案内で確認します。

### 国際郵便で送れない品物

国際郵便には、どの国にも送れない品物があります。日本郵便は、スプレー缶、香水、マニキュア、電子タバコ、モバイルバッテリーなどを挙げており、アルコール飲料・日焼け止め・ヘアトニックはアルコール濃度が24%を超えるものが対象です。国ごとに輸入を禁止している品物もあるため、日本郵便の国別の禁制品の検索で確かめます。

### 消費税の輸出免税のための書類を保存する

国内からの輸出として行う商品の販売は、消費税が免除されます（輸出免税）。国税庁によると、免税を受けるには、輸出を証明する書類を7年間保存する必要があります。郵便の場合は、20万円を超えると輸出許可書、20万円以下の小包郵便物やEMSでは、日本郵便が交付する引受けを証明する書類と発送伝票などの控えが証明書類になります。仕組みの詳細は「[越境ECの消費税｜輸出免税・インボイス・還付の基本](/ja/ec-guide/cross-border/cross-border-ec-consumption-tax/)」で解説しています。

## 越境ECに関わる法律：表示・個人情報・商標

越境ECの販売サイトでは、日本の法律と販売国の法律の両方が関わります。最初に確認したいのは、通信販売の表示、個人情報の扱い、商標の3つです。

### 特定商取引法の表示

特定商取引法は、日本の通信販売のルールを定めた法律です。消費者庁の特定商取引法ガイドによると、通信販売の広告には次のような事項の表示が必要です。

- 販売価格（送料についても表示が必要）
- 代金の支払時期と方法
- 商品の引渡時期
- 申込みの撤回や契約の解除に関する事項（返品特約を含む）
- 事業者の氏名（名称）、住所、電話番号

返品特約がない場合、購入者は商品を受け取った日から8日以内であれば、送料を自分で負担して契約を解除できます。インターネット通販では、返品特約を最終確認画面にも表示する必要があります。日本の消費者にも販売するサイトでは、この表示をそろえます。海外の消費者との取引にどの国の法律が適用されるかは、販売国の法律との関係で変わるため、弁護士に確認するのが確実です。

### 販売国の個人情報のルール

販売国によっては、日本の事業者にも個人情報のルールが適用されます。ジェトロは、EUの一般データ保護規則（GDPR）について、日本を含むEU域外の企業によるEU所在者の個人データの取得が「処理」と評価される場合にはGDPRが適用されると説明しています。EUの消費者に販売する場合は、プライバシーポリシーと個人データの扱いを専門家と確認します。

### 商標は販売する国でも取る

商標は、日本で登録していても外国では権利として成立しません。特許庁は、知的財産権は国ごとに独立しており、進出先でも商標権などを国ごとに取る必要があると説明しています。特許庁の外国出願の補助金では、中小企業の外国出願にかかる費用の半額が助成され、商標は1案件あたり60万円が上限です（2026年11月時点）。

## 越境ECの書類と許可の相談先

越境ECの書類や許可で判断に迷ったときは、テーマごとに次の窓口に相談します。

| 相談したいこと | 相談先 |
|---|---|
| 輸出申告・税関手続き | 税関の相談官、通関業者 |
| 外為法の該非判定・輸出許可 | 経済産業省（安全保障貿易管理） |
| 他法令に当たるか | 各法令を担当する省庁 |
| 酒類の免許 | 所轄の税務署 |
| 古物商許可 | 主たる営業所を管轄する警察署 |
| 販売国の輸出入制度 | ジェトロ |
| 利用規約・海外の消費者保護法・個人情報 | 弁護士 |
| 消費税・輸出免税 | 税理士、税務署 |

## 越境ECを始める前の確認チェックリスト

越境ECを始める前に、次の項目を確認しておきます。

- 個人事業主の場合、開業届を出した
- 扱う商品に国内の許可（古物商許可・酒類販売業免許など）が必要か確かめた
- 外為法のリスト規制・キャッチオール規制に当たらないか確かめた
- 他法令（植物防疫法・家畜伝染病予防法など）に当たらないか確かめた
- 国際郵便で送れない品物、販売国の禁制品に当たらないか確かめた
- 20万円を超える注文の輸出申告の方法（自分で行うか、通関業者に頼むか）を決めた
- 輸出免税のための書類を7年間保存する方法を決めた
- 特定商取引法の表示と、販売国の言語の利用規約・プライバシーポリシーを用意した
- 販売する国での商標の出願を検討した

確認の結果、国によって売れない商品が出てくることもあります。集客までAIに任せられる越境ECツールのLeapでは、商品ごとに販売国を設定でき、設定していない国では商品が表示されません。規制で売れない国には商品を出さない、といった運用をサイト側で行えます。

## よくある質問

**Q. 越境ECを始めるのに許可は必要ですか？**

A. 許可が必要かどうかは、扱う商品で決まります。中古品を仕入れて売るなら古物商許可、お酒を売るなら酒類販売業免許が必要で、外為法や他法令の対象となる商品は輸出の許可・承認が必要です。新品の雑貨などを扱う場合でも、商品が規制の対象でないかを確認してから販売を始めます。

**Q. 少額の商品を郵便で海外に送るとき、輸出申告は必要ですか？**

A. 価格が20万円以下の郵便物なら、税関への輸出申告は不要です。日本郵便の国際郵便マイページサービスで税関告知書を作り、郵便物に貼って差し出します。20万円を超える場合は、仕入書などをそろえて輸出申告を行います。

**Q. 個人でも越境ECはできますか？**

A. はい、個人でも越境ECはできます。個人事業主として始める場合は、税務署に開業届を出します。扱う商品に必要な許可や、輸出・発送の手続きは、会社が行う場合と同じように確認が必要です。

**Q. 中古品を海外に販売するには古物商許可が必要ですか？**

A. 中古品を仕入れて販売する場合は、古物商許可が必要です。自分で使っていた物や、自分で使うために買った未使用品を売るだけなら許可は不要です。判断に迷う場合は、主たる営業所を管轄する警察署に相談してください。

## まとめと気づき

越境ECに必要な書類と許可は、「扱う商品の国内の許可」「輸出の許可」「発送の書類」「販売サイトの表示と法律」の4つに分けて確認します。必要なものは越境ECという売り方ではなく、商品・送り先・送り方の組み合わせで決まります。

4つを並べると、越境ECで新しく増える確認の多くは「送る」と「売る」の場面に集中していることが分かります。逆に言えば、販売する国と商品を最初に絞り込めば、確認する法律や書類も絞り込めます。まずは1か国・少数の商品で確認を終え、判断が必要な部分は税関や専門家に相談しながら進めることが、越境ECを安心して始める近道です。始め方の全体の流れは「[越境ECの始め方｜立ち上げの流れと準備すること](/ja/ec-guide/cross-border/cross-border-ec-how-to-start/)」もあわせてご覧ください。

Leapは、集客までAIに任せられる越境ECツールです。チャットで話しかけるだけで、多言語・多通貨の越境ECサイトの作成から、SEOやメルマガなどの海外集客まで進められます。
