## 【1分で解説！】EUのデジタル公正法（DFA）案とは

EUのデジタル公正法（Digital Fairness Act、DFA）案とは、ネット上の消費者をオフラインと同じ水準で守るため、ダークパターン（消費者をだまして購入や契約に誘導する画面設計）の禁止や、サブスクの解約のしやすさなどを定めるEUの規則案です。欧州委員会が2026年11月11日に発表しました。

- **何が決まったのか**：欧州委員会が法案を発表した段階です。今後、欧州議会とEU理事会で審議され、内容が変わる可能性があります
- **日本の事業者にも関係するのか**：関係します。EUの消費者に向けて販売する事業者は、EU域外の会社でも対象になるとされています。あわせて、EU域外の事業者にEU域内の法定代理人の指名を求める改正案も出ています
- **主な中身**：「残り1点」などの偽の在庫表示の禁止、最初の表示価格に避けられない手数料・税金を含める義務、無料体験から有料への切り替え時の同意、オンラインの解約ボタン、インフルエンサー広告の明示など
- **いつから**：法案では、発効から12か月後に適用するとしています。成立の時期はまだ決まっていません

本記事では、欧州委員会の発表資料と法案の本文をもとに、越境EC事業者が知っておきたい点を解説します。情報は2026年11月27日時点のものです。

## デジタル公正法（DFA）案の発表の概要

欧州委員会は2026年11月11日、「消費者パッケージ」として次の3つの提案をまとめて発表しました。欧州委員会は、これを20年以上で最も大きなEU消費者保護法の見直しと位置づけています。

| 提案 | 中身 |
|---|---|
| デジタル公正法（DFA）案 | 不公正取引方法指令（UCPD）を、加盟国にそのまま適用される「規則」に置き換え、ダークパターン・価格表示・サブスクなどの新しいルールを加える |
| 簡素化指令案 | 消費者権利指令を改正し、アプリ内で繰り返す購入の事前の情報提供などを簡素にする |
| 消費者保護協力（CPC）規則の改正案 | 欧州委員会が大規模な違反を直接調査し、制裁金を科せるようにする。EU域外の事業者に法定代理人の指名を求める |

これまでのUCPDは「指令」だったため、加盟国がそれぞれ国内法にして運用してきました。DFAは「規則」なので、成立すればEUのすべての加盟国で同じルールが直接適用されます。欧州委員会は、国ごとのルールの違いを調べる手間が減り、事業者にとっても分かりやすくなるとしています。

## デジタル公正法はいつから適用されるのか

デジタル公正法の適用時期は、まだ決まっていません。法案は、EU官報に載った日から20日目に発効し、その12か月後から適用すると定めています。CPC規則の改正案も、発効から12か月後の適用としています。

1. 2026年11月11日：欧州委員会が法案を発表
2. 欧州議会とEU理事会で審議し、内容を修正
3. 成立後、EU官報に掲載され、20日目に発効
4. 発効から12か月後に適用開始（法案の時点の案）

審議の中で内容や適用時期が変わる可能性があるため、確定した義務として扱うのではなく、方向性として早めに把握しておく段階です。

## 日本の越境EC事業者にもデジタル公正法は関係するのか

EUの消費者に向けて販売している日本の事業者にも、デジタル公正法は関係します。

### EU域外の事業者もルールの対象

法案の説明文書では、いまのUCPDは「EUの消費者を対象にするすべての事業者に、EU域外の事業者も含めて適用される」と説明されています。DFAの適用範囲は、このUCPDの範囲をそのまま引き継ぐとされています。日本から自社ECサイトでEUの消費者に販売している場合も、対象に入ると考えておくのが安全です。

### EU域内の法定代理人の指名

CPC規則の改正案では、EUに拠点がなく、EUの消費者に向けて販売している事業者に、販売先の加盟国のいずれかで法定代理人を書面で指名するよう求めています。EU域内にあるグループ会社を法定代理人にすることも、例として挙げられています。法定代理人の名前・住所・メールアドレス・電話番号は、ウェブサイトなど消費者に向けて使う手段で公開する必要があります。改正案の条文には、この義務について中小企業を外す規定は置かれていません。

### 違反したときの制裁金

制裁金は、誰が執行するかで2つに分かれます。

| 執行する機関 | 対象 | 制裁金の上限 |
|---|---|---|
| 欧州委員会（直接執行） | EU加盟国の3分の2以上・EU人口の3分の2以上の消費者に影響する大規模な違反。中小企業は対象外 | 世界全体の年間売上高の6%まで |
| 加盟国の当局（CPCの協調行動による場合） | 複数の加盟国にまたがる違反 | 上限額を、関係する加盟国での年間売上高の4%以上に設定することを加盟国に求める |

試算の例として、EU向けの年間売上高が1億円の会社が、複数の加盟国にまたがる違反でCPCの協調行動の対象になった場合、制裁金の上限は400万円以上に設定されることになります（関係する加盟国での売上高が1億円の場合）。中小企業は欧州委員会の直接執行の対象外ですが、加盟国の当局による執行は受けます。

## デジタル公正法案で禁止・義務化される主な内容

越境ECサイトに関わる主な内容は、ダークパターンの禁止、価格表示、サブスク・定期購入、インフルエンサー広告、メールの同意の5つです。

### ダークパターンの禁止リスト（10項目）

法案の付属書には、どんな場合でも不公正とみなすダークパターンが10項目並んでいます。

| 禁止される画面設計 | ECサイトでの例 |
|---|---|
| 在庫や人気について偽る、または条件を示さない | 実際とは違う「残り1点」「ほかに5人が検討中」 |
| 注文の途中でずっと在庫・人気の表示を出し、品薄だと思わせる | カートから決済までずっと「残りわずか」を表示する |
| 断らないと追加されるデフォルト設定 | チェック済みの有料オプション、自動でカートに入る商品 |
| 断る選択を「間違った選択」のように見せる | 「お得な情報はいりません」と押させる配信停止ボタン |
| ほかに選択肢がないように見せる | 目立つプラン以外が選べないように見せる |
| すでに選んだことを何度も選び直させる | 断ったのに毎回出てくる会員登録の誘導 |
| 紛らわしい言葉や二重否定で選ばせる | 「受け取らないを選ばない」のような選択肢 |
| 価格や契約期間・自動更新を目立たなくする | 自動更新の記載だけ小さな文字にする |
| 連絡や対応が必要だと偽る通知 | 実際にはない「お客様からのメッセージがあります」 |
| 断る・取り消す手順を必要以上に多く・複雑にする | 申し込みは1クリック、解約は何ページも先 |

欧州委員会は、法案の運用の状況を見て、このリストを追加・修正できるとしています。

### 価格表示：最初に見せる価格に避けられない費用を含める

デジタル公正法案では、最初に価格を見せる段階で、購入すると避けられない手数料・税金などをすべて含めて表示することが求められます。決済画面で初めて手数料を足す「ドリップ・プライシング」を禁止する内容です。

法案の前文によると、この禁止は、金額が前もって決まっていて避けられない費用（例：一律の配送料）に当てはまります。一方、届け先の住所や注文金額、配送方法によって決まる送料のように、注文の途中で初めて決まる費用には当てはまらないとしています。国ごとに送料が変わる越境ECでは、どの費用が「前もって決まっている費用」に当たるかを整理しておくことが大切です。

あわせて、参考価格との比較で実際より大きな値引きに見せるような、紛らわしい価格比較も禁止の対象になります。

### サブスク・定期購入：無料体験・自動更新・解約ボタン

サブスクや定期購入を扱う事業者には、次のような義務が加わります。

- **無料体験**：終了日・有料になった後の価格・解約の条件を、終了前に知らせる。消費者がはっきり同意しなければ、有料の契約に切り替わらない
- **自動更新（6か月以上の契約）**：更新日の1か月前から14日前までの間に、更新日・価格・解約の条件を知らせる
- **自動更新（6か月未満の契約）**：契約期間が6か月に達する更新、または10回目の更新のどちらか早いほうの1週間前までに知らせる
- **解約ボタン**：ネットで契約できる場合、「ここで契約を解約する」などと分かりやすく書いた解約の機能を、目立つ場所に置く
- **人と話せる窓口**：契約後のオンラインのカスタマーサービスで、ほかの手段で解決しないときは、求めに応じて人と話せるようにする

### インフルエンサー広告とSNSでの集客

インフルエンサーを使って宣伝する場合は、投稿ごとに「広告」「商業的な協力」などの言葉で、広告であることをはっきり示す必要があります。インフルエンサーに依頼するブランド側も、契約などでインフルエンサーがルールを守るようにすることが求められます。

### パーソナライズ広告・価格

未成年者へのプロファイリングに基づく広告や、健康などのセンシティブなデータを使った広告の禁止は、いまはオンラインプラットフォームだけが対象です。デジタル公正法案は、これをすべてのウェブサイトとアプリに広げます。未成年者や弱い立場の消費者に、より高いパーソナライズ価格を示すことも禁止されます。

### メールマーケティングの同意

メールやSMSでの販促には、原則として消費者の事前の同意が必要です。例外として、商品を販売したときに取得したメールアドレスに、自社の似た商品を案内することはできますが、取得時と毎回のメールで、無料で簡単に配信を断れるようにしておく必要があります。

## 越境ECサイトで今から見直したいこと

デジタル公正法はまだ法案ですが、禁止リストの多くは、いまのEUの消費者法でも問題になりうる内容です。本記事では、法案の条文をもとに、EUに販売する越境ECサイトで確認したい項目を表にまとめました。

| 確認する場所 | 見直したいこと | 関係する法案の内容 |
|---|---|---|
| 商品ページ | 在庫数・閲覧人数の表示が実際のデータと一致しているか | ダークパターンの禁止リスト |
| 商品一覧・商品ページ | 一律の手数料・配送料を、最初の表示価格に含めているか | ドリップ・プライシングの禁止 |
| カート・決済画面 | 有料オプションに最初からチェックが入っていないか | ダークパターンの禁止リスト |
| メルマガの登録・配信停止 | 同意を取った記録があるか。配信停止のボタンに相手を責める言葉を使っていないか | メールの同意、ダークパターンの禁止リスト |
| 定期購入の申し込み・マイページ | 解約ボタンがあるか。更新前のお知らせを送れるか | 解約の機能、自動更新の通知 |
| SNS・インフルエンサー施策 | 依頼した投稿に「広告」の表示を入れる契約になっているか | インフルエンサー広告 |
| 会社情報・事業者情報のページ | 法定代理人の情報を載せる場所を用意できるか | CPC規則の改正案 |

メルマガで海外の顧客に案内を送る場合は、配信リストをどこで、どんな同意を得て集めたかを記録しておくことが前提になります。集客までAIに任せられる越境ECツールのLeapのように、CRMにCSVで顧客情報を取り込んで多言語メルマガを配信できるツールを使う場合も、取り込む前に同意の有無を確かめておくと安心です。

## よくある質問

**Q. デジタル公正法（DFA）とは何ですか？**

A. デジタル公正法とは、ダークパターンの禁止やサブスクの解約のしやすさなどを定めるEUの規則案で、欧州委員会が2026年11月11日に発表しました。いまの不公正取引方法指令を規則に置き換え、ネット特有の問題に対応するルールを加える内容です。

**Q. デジタル公正法のダークパターン規制はいつから適用されますか？**

A. 適用の時期はまだ決まっていません。法案では発効から12か月後に適用するとしていますが、欧州議会とEU理事会での審議がこれからのため、成立の時期や内容は変わる可能性があります。

**Q. 日本の会社にもデジタル公正法は適用されますか？**

A. EUの消費者に向けて販売している場合は、日本の会社にも関係します。法案の説明文書では、EU域外の事業者もEUの消費者を対象にしていれば対象になるとされ、CPC規則の改正案ではEU域内の法定代理人の指名も求めています。

**Q. デジタル公正法に違反すると制裁金はいくらですか？**

A. 欧州委員会が直接執行する大規模な違反では、世界全体の年間売上高の6%までの制裁金が科される可能性があります。中小企業はこの直接執行の対象外ですが、加盟国の当局による執行では、関係する加盟国での年間売上高の4%以上を上限とする制裁金の仕組みが求められます。

## まとめと気づき

デジタル公正法案は、「残り1点」の偽表示、チェック済みのオプション、見つけにくい解約手続きなど、ECサイトで見かけることのある画面設計を、EU全体で一律に禁止しようとする法案です。EU域外の事業者も対象とされ、法定代理人の指名まで求められる見込みです。

今回の法案から見えてくるのは、EU向けの越境ECでは「何を売るか」「どう届けるか」に加えて、「サイトの画面をどう作るか」も規制の対象になってきたことです。成立はまだ先ですが、在庫表示・価格表示・解約の導線は、日本向けのサイトの設計をそのまま使っていることも多い部分です。EUに売るなら、法案の禁止リストを手元に置き、販売を広げる前にサイトの画面を一度見直しておくことが、後から慌てないための近道になります。

Leapは、集客までAIに任せられる越境ECツールです。チャットで話しかけるだけで、多言語・多通貨の越境ECサイトの作成から、SEOやメルマガなどの海外集客まで進められます。
