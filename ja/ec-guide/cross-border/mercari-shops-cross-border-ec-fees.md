## 【1分で解説！】メルカリShopsは国内発送だけで海外に売れる

メルカリShopsの越境販売とは、メルカリまたはメルカリと公式に連携した越境EC事業者が海外の購入者に代わって商品を買い、輸出・通関・海外発送までを担う仕組みです。出店者は、指定された日本国内の住所へ、国内の取引と同じように発送するだけで海外に販売できます。

手数料は国内の販売と同じで、越境販売だからといって別の手数料はかかりません（2026年11月時点）。メルカリShopsの販売手数料は税込価格の10%、売上金の振込手数料は1回200円で、初期費用と月額費用は無料です。

一方で、海外の購入者とのやり取りはメルカリや越境EC事業者が行うため、出店者が海外の顧客と直接つながる仕組みではありません。本記事では、公式情報をもとに仕組み・手数料・設定方法を整理し、自社ECで海外に売る場合との違いを解説します。

## メルカリShopsの越境販売の仕組み

メルカリShopsの越境販売では、出店者が海外の購入者と直接取引するのではなく、間に入る事業者が「国内の購入者」として商品を買います。メルカリShopsの公式サイトでは、海外の購入者とのやり取り、発送、輸出・通関などの手続きは越境EC事業者またはメルカリが行うため、出店者側で特別な対応は不要と説明されています。

### 取引の流れ

メルカリShopsの公式記事とメルカリのヘルプで説明されている流れは、次のとおりです。

1. 海外の購入者が、越境EC事業者のサイトやメルカリのアプリから商品を注文する
2. 越境EC事業者またはメルカリの公式アカウントが、出店者から商品を購入する
3. 出店者は、指定された日本国内の住所へ、通常の梱包で発送する
4. 越境EC事業者またはメルカリが商品を受け取り、海外の購入者へ発送する

出店者の発送先は日本国内なので、海外向けの梱包や輸出書類を用意する必要はありません。メルカリのヘルプでは、複数の商品が購入された場合も、取り違えを防ぐために同梱せず取引ごとに発送するよう案内されています。

### 海外の購入者が使う2つの窓口

海外の購入者がメルカリShopsの商品を買う窓口は、大きく分けて2つあります。

- **公式連携の越境EC事業者**：メルカリを使えない海外在住の購入者からの注文を、連携した事業者が受けて代わりに購入します。メルカリShopsでは2023年に導入されました。メルカリのヘルプには、公式連携している越境EC事業者が54社掲載されています（2026年11月時点）
- **メルカリ グローバルアプリ**：メルカリ初の世界共通アプリで、海外の購入者が日本の「メルカリ」と「メルカリShops」の商品を閲覧・購入できます。2025年9月30日に台湾・香港で始まり、2026年6月17日（米国時間）に米国でも提供が始まりました

グローバルアプリについて、メルカリのプレスリリースでは、メルカリShopsの出店者は設定・申請などの特別な対応なしに海外の購入者へ販売できると説明されています。決済はStripe、配送は佐川急便などのパートナーと連携し、AIによるリアルタイム翻訳も備えています。米国向けの発表では、発送前にメルカリがすべての商品をチェックする「全品検品」と、配送中の破損・紛失への無料の補償が紹介されています。

### 販売できる国と売れているジャンル

メルカリShopsの公式サイトによれば、越境販売は120の国・地域で展開されており、販売先の上位3つは中国・アメリカ・台湾です（2026年11月時点）。同じページでは、2025年4月〜2026年4月の越境販売の流通総額が前年同期比で2倍に伸びたとしています。

メルカリShopsの公式記事では、海外からの注文が多いジャンルとして「おもちゃ・ホビー・グッズ」「ファッション」「本・雑誌・漫画」が挙げられています。

## メルカリShopsの越境販売にかかる手数料

メルカリShopsの越境販売にかかる手数料は、国内の販売と同じです。メルカリShopsの公式記事では、越境販売であっても送料や手数料が別途かかることはないと明記されています。

| 費用 | 金額（2026年11月時点） |
|---|---|
| 初期費用 | 無料 |
| 月額費用 | 無料 |
| 販売手数料 | 税込価格の10%（送料別で出品した場合は、商品価格と送料の合計に10%） |
| 振込手数料 | 売上金の振込1回につき200円 |
| 越境販売の追加手数料 | なし |
| 国際送料・輸出手続き | 出店者の負担なし（越境EC事業者またはメルカリが行う） |

出店者が負担する送料は、国内の指定住所までの送料です。海外の購入者が支払う国際送料やサービス料は、越境EC事業者やメルカリ側で扱われるため、出店者の販売手数料とは別の話になります。

### 手数料の試算例

公開されている料金から、1か月の手数料を試算すると次のようになります。

- 条件：1点3,000円（税込・送料込み）の商品が、海外向けに月20点売れた場合
- 売上：3,000円 × 20点 = 60,000円
- 販売手数料：60,000円 × 10% = 6,000円
- 振込手数料：200円（月1回振り込まれた場合）
- 出店者の手元に残る金額：53,800円（ここから国内の指定住所までの送料と商品の原価を差し引きます）

固定費がかからないため、売れなかった月の費用は0円です。少ない点数から海外の反応を試すには、始めやすい料金体系と言えます。

## メルカリShopsで越境販売を始める方法

メルカリShopsで越境販売を始めるには、ショップ管理画面で越境EC事業者からの注文を受け付ける設定にするだけです。メルカリShopsの公式記事によれば、この設定は初期状態で「受け付ける」になっています。

1. メルカリShopsでショップを開設する
2. ショップ管理画面の「設定」から「ショップ情報編集」を開く
3. 「越境EC事業者からの注文受付」で「受け付ける」を選ぶ
4. 商品を登録して販売する

越境販売を利用したくない場合は、同じ項目で「受け付けない」を選べます。

### キャンセル・返品・販売できる商品

メルカリShopsの公式記事では、キャンセル・返品は次のように扱われると説明されています。

- **キャンセル**：海外の購入者が越境EC事業者を通じて依頼し、国内の取引と同じように処理する
- **返品**：海外の購入者が越境EC事業者に商品を返送し、越境EC事業者から出店者へ返品される
- **紛失・破損・トラブル**：まず越境EC事業者が窓口になる

販売できる商品は、日本国内で販売でき、メルカリのガイドラインで認められているものに限られます。ガイドラインで禁止されている商品は、越境販売でも販売できません。

## メルカリShopsと自社ECで海外に売る場合の違い

メルカリShopsの越境販売と自社ECでの海外販売の一番の違いは、海外の顧客と直接つながるかどうかです。メルカリShopsは、海外の購入者とのやり取りや発送をメルカリや越境EC事業者に任せられる一方、出店者が海外の顧客情報を持ち、繰り返し買ってもらうための関係を作る仕組みではありません。自社ECは、決済・配送・多言語対応を自分で整える手間がかかる一方、ブランドの見せ方や海外の顧客との関係を自分で作れます。

| 項目 | メルカリShops（越境販売） | 自社EC（集客までAIに任せられる越境ECツールのLeap） |
|---|---|---|
| 料金 | 初期費用・月額費用は無料 | フリープラン0円、スタータープラン月額9,800円（税抜）など |
| 手数料 | 販売手数料10%、振込手数料200円/回 | 売上の6%（クレジットカード決済手数料を含む） |
| 多言語 | 海外の購入者側のサイト・アプリで対応（グローバルアプリはAI翻訳）。出店者のページは日本語のまま | 多言語のECサイトを作成できる（言語数はプランによる） |
| 多通貨・決済 | 越境EC事業者またはメルカリが対応 | 米ドル・ユーロ・日本円。クレジットカード（Visa・Mastercard） |
| 国際配送・通関 | 越境EC事業者またはメルカリが行う | 自社で手配する |
| 集客機能 | メルカリのアプリ・越境EC事業者のサイトの利用者に表示される。クーポンなどの販促機能あり | 多言語ブログの自動作成（SEO/AIO）、CRM、多言語メルマガ配信 |
| 海外の顧客との関係 | 海外の購入者とのやり取りは発生しない | 顧客情報を自社で管理できる |
| BtoB対応 | 公式情報では確認できず | BtoB専用カート（企業ごとの価格設定・見積もり依頼・請求書払い） |

※メルカリShopsは公式サイト・公式記事、Leapは料金ページの情報（いずれも2026年11月時点）。

デザインや機能を細かく作り込みたい場合は、Leapよりカスタマイズ性の高いShopifyなどのツールが向いています。また、Leapでは国際配送の手配は自社で行う必要があり、発送まで任せたい場合はメルカリShopsの越境販売のほうが手間がかかりません。

### 使い分けの考え方

使い分けは、海外販売で何を目指すかで決まります。

- **在庫を国内発送だけで海外にも売りたい人**：メルカリShopsの越境販売が向いています。設定が1か所で済み、固定費もかからないため、海外の反応を試す最初の一歩に使えます
- **自社ブランドとして海外の顧客を増やしたい人**：自社ECが向いています。海外向けのSEOやメルマガで顧客と関係を作りたい場合は、集客までAIに任せられる越境ECツールのLeapのように、サイト作成から海外集客までまとめて進められるツールが選択肢になります

両方を組み合わせ、メルカリShopsで海外の需要が分かった商品を、自社ECで本格的に売るという進め方もあります。

## よくある質問

**Q. メルカリShopsの越境販売に追加の手数料はかかりますか？**

A. かかりません。越境販売でも国内の販売と同じく、販売手数料10%と振込手数料200円だけで、送料や手数料が別途かかることはないとメルカリShopsの公式記事に明記されています（2026年11月時点）。

**Q. 海外への発送は自分でする必要がありますか？**

A. 必要ありません。出店者は指定された日本国内の住所へ発送するだけで、海外への発送や輸出・通関の手続きは越境EC事業者またはメルカリが行います。

**Q. 英語など外国語でのやり取りは必要ですか？**

A. 必要ありません。海外の購入者とのやり取りは越境EC事業者またはメルカリが行い、メルカリのヘルプでは、公式アカウントとの連絡も日本語でできると案内されています。

**Q. 越境販売を受け付けないようにできますか？**

A. できます。ショップ管理画面の「設定」から「ショップ情報編集」を開き、「越境EC事業者からの注文受付」で「受け付けない」を選びます。

## まとめと気づき

メルカリShopsの越境販売は、国内と同じ発送・同じ手数料のまま、120の国・地域の購入者に商品を届けられる仕組みです。グローバルアプリの広がりによって、海外の購入者がメルカリShopsの商品を直接買える場面も増えています。

ただし、越境販売で増えるのは「海外で売れる機会」であり、「海外の顧客との関係」ではありません。海外の購入者とのやり取りは間に入る事業者が担うため、誰が買ったのかを知り、もう一度買ってもらう仕組みは、出店者の手元には残りにくくなります。まずメルカリShopsで海外の需要を確かめ、手応えのある商品から自社の顧客づくりへ広げていく、という順番で考えると、2つの販路を無理なく使い分けられます。

Leapは、集客までAIに任せられる越境ECツールです。チャットで話しかけるだけで、多言語・多通貨の越境ECサイトの作成から、SEOやメルマガなどの海外集客まで進められます。
