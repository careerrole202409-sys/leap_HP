## 【1分で解説！】Amborasの料金体系を一気に押さえる
Amborasは、2026年春にYコンビネーター（YC）のバッチに採択されたAIネイティブのECプラットフォームです。ストアのデザイン生成からA/Bテスト、メールキャンペーンの自動配信まで、AIがほぼすべての運営業務を担う点が最大の特徴で、EC事業者の間で急速に注目を集めています。
本記事では、その料金体系について徹底解説します。具体的には、Basic・Pro・Advanced・Plusの4プラン（2026年11月時点）の月額費用と提供機能の違い、無料トライアルや30日間ラーンチ保証の詳細、そしてShopifyとのコスト比較（日本円換算シミュレーション含む）まで、導入を検討している担当者が知りたい情報を一冊にまとめました。
結論から言えば、Amborasはクレジットカードなしの無料枠でストアを作り始められますが、独自ドメインで公開して本格的に販売するには有料プランが必要です。2026年11月時点の料金ページでは、有料プランはBasic（月額49ドル）・Pro（月額105ドル）・Advanced（月額299ドル）・Plus（要問い合わせ）の4つです（いずれも月払い）。一方で、AIによる自動化ツール群がすべて標準搭載されている点が他プラットフォームと大きく異なります。AIツールを個別に契約するコストと比較すれば、Amboras単体のコストパフォーマンスは非常に高い水準にあります。

## Amborasは無料？無料でできることと有料になること（2026年11月時点）

Amborasは無料で始められますが、無料のままでは独自ドメインでの本格的な販売はできません。AmborasのFAQでは、クレジットカードなしで無料枠を使ってストアを作ることができ、独自ドメインで公開するときや有料の機能を使うときに支払いが必要になると説明されています。

| 項目 | 内容（2026年11月時点） |
|---|---|
| 無料でできること | クレジットカードなしで、ストアを一通り作ること |
| 有料プランが必要になること | 独自ドメインでの公開、有料の機能の利用 |
| 有料プランの月額（月払い） | Basic 49ドル／Pro 105ドル／Advanced 299ドル／Plus 要問い合わせ |
| 年払い | 月払いより20%安い |
| 30日間ローンチ保証 | Basic・Pro・Advancedが対象 |
| 請求の通貨 | 日本から開くと料金ページは日本円で表示されるが、請求は米ドル |

## Amborasの料金プランは全部で4つ
Amborasの料金体系は、事業規模に応じて段階的に選べるよう設計されています。2026年11月時点では月払いと年払い（20%オフ）の2通りの請求サイクルが用意されており、月払いの場合は以下の4プランが提供されています。

**Basic：月額49ドル（2026年11月時点）**
料金ページで「最初のストアを始めて運営するためのプラン」と紹介されている、スタートアップ・個人事業主向けのプランです。AIストアデザイナー、AIによる商品画像の生成・補正、メールキャンペーン＆フロー配信が含まれ、1店舗・1ユーザー・独自ドメイン1つまで使えます（2026年11月時点）。多通貨・自動税計算、A/B/nテスト、優先サポートは含まれません。

**Pro：月額105ドル（2026年11月時点）**
最も人気の高いプラン（Most Popular）として公式に紹介されており、成長を目指すブランド向けです。Basicの機能に加え、最大5店舗・10名・独自ドメイン5つまで使え、AIによるA/B/nテスト、多通貨・自動税計算、優先サポートが含まれます（2026年11月時点）。高度なアナリティクスは含まれません。越境ECや複数店舗展開を視野に入れている事業者に特に刺さるプランです。

**Advanced：月額299ドル（2026年11月時点）**
料金ページで「複数のストアを拡大するチーム向け」と紹介されているプランです。Proの機能に加え、Slackチャンネルでのサポートと高度なアナリティクスが含まれます。店舗数・メンバー数・独自ドメイン数の上限はProと同じ5店舗・10名・5つで、専任のサクセスマネージャーは含まれません（2026年11月時点）。

**Plus：要問い合わせ（2026年11月時点）**
大量の取引がある事業者向けのプランです。Advancedの機能に加え、ストア数・メンバー数が無制限になり、毎月のAIクレジットも無制限、専用のAI処理能力と専任のサクセスマネージャーが付きます（2026年11月時点）。料金はチームへの問い合わせで決まります。

## 無料で始められる。有料プランには30日間保証がある
「Amborasは無料で使えますか？」という問いへの回答は、2026年11月時点では「始めるだけなら無料」です。クレジットカードなしの無料枠でストアを作れますが、独自ドメインで公開する場合や有料の機能を使う場合は有料プランが必要です。
また、AmborasはBasic・Pro・Advancedの各プランに「30日間ラーンチ保証（30-day launch guarantee）」を設けています（2026年11月時点）。これは、ストアを24時間以内に公開できること、かつ最初の30日間に1件も売上が立たなかった場合に全額返金を保証するというものです。これはシンプルな返金保証というよりも、「AI が運営する店舗なら最低限の成果は保証できる」という自信の表れとも言えます。
また、プランの変更はいつでも可能で、アップグレードでもダウングレードでもデータのマイグレーションは不要です。日割り請求が適用されるため、試してから判断することができます。このあたりの柔軟性は、Shopifyと比較しても引けを取りません。

## トランザクション（取引）手数料の有無
Amborasの公式Pricingページを精査した結果、現時点では追加のトランザクション手数料の記載は確認されていません。決済にはStripeが採用されており、通常のStripe手数料（国内カード決済：2.9% + 30セント前後、国際カードは追加料率）が適用される形となります。
これはShopifyと比較して重要な差異です。Shopifyでは、Shopifyペイメント以外の外部決済サービスを利用した場合、プランに応じた取引手数料（2026年11月時点の日本向け料金ページでBasic：2%、Grow：1%、Advanced：0.6%）が別途加算されます。つまり、Amborasは「月額料金 + Stripe手数料のみ」というシンプルな料金体系であり、複雑な手数料計算が不要です。
ただし、決済手数料の詳細はStripe契約の内容に依存するため、導入前にStripeとの契約条件を確認することをお勧めします。

## Shopifyとのコスト比較：日本円換算シミュレーション
ここでは、中小ECチームが最も比較検討しやすいミドルレンジのプラン同士で費用を比較してみます。

### スタートアップ・個人事業主（1店舗・小規模運営の場合）
| | Amboras Basic | Shopify Basic |
|---|---|---|
| 月額（月払い、2026年11月時点） | $49 | 4,850円 |
| AIツール | 標準搭載 | 別途アプリが必要 |
| 取引手数料 | なし（Stripe手数料のみ） | 外部決済利用時2% |

一見、Shopify Basicの方が月額は安く見えます。しかしShopifyでは、AIによる商品画像補正・メール自動化・A/Bテストなどを実現しようとすると、各機能を提供するアプリを別途契約する必要があります。例えばKlaviyoなどのメール自動化ツールは月額数千円〜数万円かかります。これらを積み上げると、Amborasのほうが総コストを抑えられるケースは少なくありません。

### 中小企業・複数店舗・越境EC展開チーム（2〜5店舗規模）
| | Amboras Pro | Shopify Grow |
|---|---|---|
| 月額（月払い、2026年11月時点） | $105 | 13,500円 |
| 最大店舗数 | 5店舗（1サブスクリプション） | 基本1店舗 |
| 多通貨・多言語 | 標準搭載 | 標準搭載（現地通貨での表示はShopifyペイメントが必要） |
| A/Bテスト（自律型） | 標準搭載 | 別途アプリ |

越境ECや複数ブランドの同時展開を考えている場合、Amboras Proの「5店舗を1サブスクリプションで管理」（2026年11月時点）というモデルは大きなコストメリットになります。Shopifyで同じことをやろうとすると、店舗ごとに月額料金が発生するためです。

## Shopify移行（マイグレーション）は無料で対応
「今Shopifyを使っているが、Amborasに乗り換えたい」という場合、移行コストも気になるところです。Amborasの公式FAQによれば、すべての有料プランでShopifyからの移行（商品・顧客・注文・リダイレクト）を無料でサポートしており、ほとんどの移行は48時間以内に完了するとされています。SEO上のリダイレクト処理も含まれる点は、特に集客面を重視する越境EC事業者にとって安心感があります。
既存ストアのデータを失わずに乗り換えられるという点で、移行ハードルは比較的低いと言えるでしょう。まずは現在の月額コストとアプリ費用の合計を洗い出し、Amborasとの差分を試算してみることをお勧めします。

## 実際の事業者評価：G2・Capterraのレビューから読み解く
Amborasは2025〜2026年にかけてサービスを本格展開したばかりの新興プラットフォームであり、G2やCapterraでのレビュー件数はまだ限定的です。ただし、YCバッチ採択という信頼性の裏付けと、公式サイトに掲載されているユーザーの声を見ると、「セットアップの速さ（2分以内で立ち上がる）」「AIが自動でストアを最適化し続ける点」「既存プラットフォームに比べてプラグインやエージェンシーへの依存度が下がる点」を評価するコメントが目立ちます。
一方で、プラットフォームとしての歴史が浅く、大規模なカスタマイズやERP連携が必要なケースでは機能の限界に直面するリスクもあります。Shopifyが持つ豊富なアプリエコシステム（8,000以上のアプリ）とは、現時点では差があることを理解したうえで導入判断をすることが重要です。

## 海外にも販売する場合のAmborasの料金

海外にも販売するなら、Amborasでは多通貨と自動の税計算が含まれるProプラン（月額105ドル、月払い）以上が目安になります。2026年11月時点のAmborasの料金ページでは、Basicプラン（月額49ドル）に「多通貨と自動の税計算（Multi-currency and automatic tax）」は含まれていません。

海外販売でかかる費用は、主に次の3つです（2026年11月時点）。

1. **月額料金**：Proは月額105ドル、Advancedは月額299ドル（月払い）で、年払いにすると20%安くなります。請求は米ドルのため、日本の事業者は為替レートによって円での負担が変わります。
2. **決済手数料**：AmborasのFAQでは、決済手数料は決済処理の実費で、米国のカードで2.9%＋30セントが目安、EUではそれより低いと説明されています。Amboras独自の取引手数料は上乗せしないとしています。
3. **送料と関税**：AmborasのFAQによると、送料は地域・重量・金額ごとに設定でき、連携する配送業者の割引料金で送り状を印刷できます。関税は購入時に前もって集める方法（DDP）か、配送業者に任せる方法（DAP）を選べます。

料金を比べるときは、月額だけでなく、売上にかかる手数料も合わせて計算することが大切です。たとえば集客までAIに任せられる越境ECツールのLeapは、月額料金（フリープランは0円）に加えて、越境ECの売上の6%（クレジットカード決済手数料を含む）がかかる仕組みです（2026年11月時点）。

## FAQ：Amborasの料金プランに関するよくある質問
**Q1. 無料トライアルはありますか？完全無料で試す方法はありますか？**
はい。2026年11月時点では、クレジットカードなしの無料枠でストアを作って試せます。独自ドメインでの公開や有料の機能には有料プランが必要ですが、Basic・Pro・Advanced各プランには「30日間ラーンチ保証」が付属しており、最初の30日間に売上が発生しなかった場合は全額返金されます。事実上のリスクフリー期間として機能するため、まずは試してみるという判断もできます。

**Q2. 年払いに切り替えると実際どのくらい安くなりますか？**
Amborasは年払いを選択すると月額費用が20%割引されます。2026年11月時点の料金ページでは、Basicは年額470.40ドル（月払いより年117.60ドル安い）、Proは年額1,008ドル（月払いより年252ドル安い）です。事業規模の見通しが立っている場合は、年払いへの切り替えを積極的に検討する価値があります。

**Q3. 越境ECを展開したい場合、どのプランが適していますか？**
2026年11月時点では、多通貨・自動税計算がProプランから利用可能になるため、越境ECを本格展開するのであればProプラン以上を選ぶことをお勧めします。また、複数の海外向けストアを言語・地域ごとに分けて運営したい場合も、最大5店舗を1サブスクリプションで管理できるProの構成が合理的です。

**Q4. 海外の顧客がカードで支払うと、決済手数料はいくらかかりますか？**

A. AmborasのFAQでは、決済手数料は決済処理の実費で、米国のカードで2.9%＋30セントが目安、EUではそれより低いと説明されています（2026年11月時点）。Amborasはこれとは別の取引手数料を上乗せしないとしていますが、海外で発行されたカードや通貨の両替にかかる条件はFAQに書かれていないため、契約前にAmborasに問い合わせて確かめることをおすすめします。

## まとめ：Amborasの料金は「AIコミコミ」で考えると安い
本記事では、Amborasの4つの料金プランの内容と費用、無料版・トライアルの実態、トランザクション手数料の構造、Shopifyとのコスト比較について解説しました。
最後に整理すると、Amborasの料金の本質は「AIによる自動化ツール群が標準搭載された状態での月額費用」という点にあります。Shopifyなどの既存プラットフォームでは、メール自動化・A/Bテスト・商品画像補正・多言語対応などをすべてアプリで賄うとなると、月額コストが想定以上に膨らむことは珍しくありません。Amborasはその積み上げコストを一本化したシンプルな体系であり、特に複数店舗・越境EC展開を視野に入れた中小企業にとってはコストパフォーマンスの高い選択肢です。
一方で、プラットフォームとしての成熟度はShopifyに及ばない部分もあります。自社の事業規模・技術要件・将来の成長計画を踏まえ、まずは30日間保証を活用して実際の使い勝手を確かめてみることが最善の判断材料になるでしょう。
