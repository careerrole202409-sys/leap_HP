## 【一分钟速览】跨境电商需要的文件与许可

跨境电商需要哪些文件和许可，并不取决于"跨境电商"这种销售方式本身，而是取决于"卖什么商品""寄到哪个国家""用什么方式寄送"。需要确认的内容主要有以下4项：

1. **经营商品所需的日本国内许可**：收购二手商品再销售需要古物商许可，销售酒类需要酒类销售业许可等
2. **出口许可**：商品是否属于外汇法（《外汇及对外贸易法》）的出口管制对象，或植物防疫法、家畜传染病预防法等"其他法令"的管制对象
3. **寄送文件**：邮寄需要海关申报单，价值超过20万日元时需要办理出口申报并提交发票等
4. **网店的标示与法律**：日本特定商取引法的标示、销售国的消费者保护与个人信息规则、商标

本文面向准备开展跨境电商的中小企业负责人，根据日本海关、经济产业省、国税厅等机构的公开信息，对这4项内容进行整理。法律的具体适用会因商品和交易形式而不同，需要判断的部分，请向本文后半部分介绍的咨询窗口确认。

## 跨境电商所需文件、许可与法律的全貌

把跨境电商涉及的文件、许可和法律按"开始经营""采购与经营商品""寄往海外""在网店销售"4个环节来划分，会更容易理清。

| 环节 | 主要文件、许可与法律 | 主要确认窗口 |
|---|---|---|
| 开始经营 | 开业申报（个体经营者） | 税务署 |
| 采购与经营商品 | 古物商许可、酒类销售业许可等 | 警察署、税务署等 |
| 寄往海外 | 外汇法出口许可、其他法令的许可与批准、海关申报单、出口申报书、发票 | 经济产业省、各法令主管部门、海关、报关行 |
| 在网店销售 | 特定商取引法的标示、销售国法律、商标 | 消费者厅的指南、律师、特许厅 |

已经在日本经营网店的企业，"开始经营"环节通常已经准备好，跨境电商新增的确认事项主要集中在"寄往海外"和"在网店销售"这两个环节。

## 开始做跨境电商需要的文件

以个体经营者身份开始做跨境电商时，需要向税务署提交开业申报（个人事业开业・废业等申报书）。根据国税厅的说明，开业申报的提交期限为开始经营当年的确定申报（年度纳税申报）期限之前。

选择蓝色申报的，还需要提交蓝色申报承认申请书。提交期限原则上为希望采用蓝色申报的当年3月15日之前；如果在当年1月16日以后新开始经营，则为开始经营之日起2个月以内。

## 做跨境电商需要许可吗

是否需要许可取决于经营的商品。采购全新的杂货或服装进行销售，与销售二手商品或酒类相比，所需的许可并不相同。

### 收购二手商品再销售：需要古物商许可

收购二手商品再销售时，需要取得基于古物营业法的古物商许可。大阪府警察的问答说明，只是出售自己用过的物品，或为自用而购买但未使用的物品，不需要许可；而为了转卖而收购旧物，则需要许可。

根据东京警视厅的说明，申请窗口为管辖主要营业所所在地的警察署，手续费为19,000日元（截至2026年11月）。

### 销售酒类：需要酒类销售业许可

通过互联网持续销售酒类时，需要按每个销售场所，取得所在地管辖税务署长颁发的酒类销售业许可。国税厅表示，利用互联网销售酒类需要哪种许可，要根据订单受理与交付方式等逐案判断。

酒类销售业许可中有"进出口酒类批发业许可"等类别，可以批发出口的酒类。直接向海外消费者销售时需要哪种许可，取决于具体的销售方式，建议在规划阶段向所辖税务署确认。

### 食品、化妆品等：同时确认日本和销售国的规则

食品、化妆品、保健食品、药品等，根据生产和销售方式的不同，在日本国内也可能需要许可或备案，销售国对成分、标示、注册也有各自的规定。日本国内的规则可以向保健所或都道府县的主管窗口确认，销售国的规则可以查阅日本贸易振兴机构（JETRO）的"进出口基本制度"。JETRO整理了约60个主要国家和地区的进出口制度。

## 出口所需的许可：外汇法与其他法令

从日本寄出商品之前，需要确认商品是否属于需要出口许可或批准的对象。是否属于管制对象，取决于商品种类和目的地国家。

### 外汇法的出口管制（安全保障贸易管理）

外汇法的出口管制，是指出口武器以及可能被用于开发武器等的货物和技术时，需要取得经济产业大臣许可的制度。根据经济产业省的说明，管制分为以下2种：

- **清单管制**：属于《出口贸易管理令》所列品目的货物，除可适用例外规定的情况外，无论目的地和用途，都需要取得许可
- **全面管制（Catch-all管制）**：即使不属于清单管制的货物，如果可能被用于开发大规模杀伤性武器或常规武器，也需要取得许可（面向部分实施严格出口管理的国家除外）

调查商品是否属于清单管制的过程称为"该非判定"。经济产业省不代为进行该非判定，需要出口方自行判定。经营电子元器件、机械、化学品等商品时，也可以确认能否从制造商处获取该非判定书。

### 其他法令的许可与批准

"其他法令"是指海关相关法律以外、对进出口规定了许可或批准等要求的法律。根据日本海关的说明，需要其他法令许可或批准的货物，必须取得相应许可并向海关证明，否则不予出口放行。海关列出的主要其他法令如下（截至2026年4月）。

| 法令 | 主要品目 |
|---|---|
| 外汇法（出口贸易管理令） | 武器与化学武器、麻醉品、华盛顿公约（CITES）适用物品、制裁对象货物等 |
| 文化财保护法 | 重要文化财、重要美术品、天然纪念物等 |
| 鸟兽保护管理法 | 野生鸟类、兽类及其加工品、鸟蛋等 |
| 家畜传染病预防法 | 偶蹄类动物、家禽及其肉类、香肠、火腿等 |
| 植物防疫法 | 植物（包括种子、果实等）、有害植物、有害动物 |
| 狂犬病预防法 | 狗、猫、浣熊、狐狸、臭鼬 |

日本海关表示无法答复货物是否属于其他法令管制对象的咨询，请向负责各项法令的主管部门确认。

## 跨境电商寄送所需的文件

跨境电商寄送商品时需要的文件，取决于寄送方式和商品价值。通过邮政寄送时，手续以价值是否超过20万日元为界有所不同。

### 邮政寄送：海关申报单与出口申报

根据日本海关的说明，邮件的手续如下：

1. **20万日元以下**：无需向海关办理出口申报。通过日本邮政的"国际邮件My Page服务"制作海关申报单，贴在邮件上寄出即可。如果海关查验时发现需要其他法令许可或批准的物品，海关会寄送明信片告知所需手续。
2. **超过20万日元**：需要向海关办理出口申报。需准备发票等文件，委托日本邮政或报关行办理通关手续，或自行申报。

海关申报单的价格栏应填写FOB价格（原则上为实际结算金额）。

### 出口申报所需的文件

办理出口申报时，需要向海关提交出口申报书，并附上发票或可替代发票的文件。根据日本海关的说明，视情况还需要以下文件：

- 装箱单（Packing List）
- 其他法令的许可证、批准证等（属于其他法令管制的货物）
- 与关税减免等相关的文件

使用国际快递时需要准备哪些文件，请查看快递公司的指南。

### 国际邮件不能寄送的物品

有些物品无法通过国际邮件寄往任何国家。日本邮政列举了喷雾罐、香水、指甲油、电子烟、充电宝等；酒精饮料、防晒霜、生发水则是酒精浓度超过24%的才属于禁寄范围。部分国家还有各自禁止进口的物品，可以通过日本邮政的"各国禁寄物品查询"确认。

### 保存消费税出口免税所需的文件

从日本出口销售商品可以免征消费税（出口免税）。根据国税厅的说明，享受免税需要将证明出口的文件保存7年。通过邮政寄送时，价值超过20万日元的以出口许可书作为证明；20万日元以下的包裹或EMS，以日本邮政出具的收寄证明文件及寄件单底联等作为证明。详细内容请参阅《[跨境电商的消费税](/zh-hans/ec-guide/cross-border/cross-border-ec-consumption-tax/)》。

## 跨境电商涉及的法律：标示、个人信息与商标

跨境电商网店同时受日本法律和销售国法律的约束。首先需要确认的是通信销售的标示、个人信息的处理和商标这3项。

### 特定商取引法的标示

特定商取引法是规定日本通信销售规则的法律。根据消费者厅的特定商取引法指南，通信销售的广告需要标示以下事项：

- 销售价格（运费也需要标示）
- 货款的支付时间和方式
- 商品的交付时间
- 撤回订单或解除合同的相关事项（包括退货特约）
- 经营者的姓名（名称）、地址、电话号码

如果没有退货特约，购买者可以在收到商品之日起8天内自行承担退货运费解除合同。网上销售时，退货特约还需要在最终确认页面上标示。如果网店也面向日本消费者销售，需要备齐这些标示。与海外消费者的交易适用哪个国家的法律，会因销售国的法律而异，建议向律师确认。

### 销售国的个人信息规则

根据销售国的不同，个人信息规则也可能适用于日本企业。JETRO说明，关于欧盟《通用数据保护条例》（GDPR），包括日本在内的欧盟以外的企业获取欧盟境内人员的个人数据，如果被认定为"处理"，则适用GDPR。面向欧盟消费者销售时，建议与专业人士一起确认隐私政策和个人数据的处理方式。

### 在销售国也要注册商标

在日本注册的商标，在国外并不能成立权利。日本特许厅说明，知识产权在各国是相互独立的，在进入的市场也需要分别取得商标权等权利。特许厅的海外申请补助金可为中小企业补助海外申请费用的一半，商标每件上限为60万日元（截至2026年11月）。

## 跨境电商文件与许可的咨询窗口

对跨境电商的文件或许可有疑问时，可以按主题向以下窗口咨询。

| 咨询内容 | 咨询窗口 |
|---|---|
| 出口申报、海关手续 | 海关咨询官、报关行 |
| 外汇法的该非判定、出口许可 | 经济产业省（安全保障贸易管理） |
| 是否属于其他法令管制 | 负责各项法令的主管部门 |
| 酒类许可 | 所辖税务署 |
| 古物商许可 | 管辖主要营业所的警察署 |
| 销售国的进出口制度 | JETRO |
| 用户协议、海外消费者保护法、个人信息 | 律师 |
| 消费税、出口免税 | 税理士、税务署 |

## 开始跨境电商前的确认清单

开始做跨境电商之前，请确认以下事项：

- 个体经营者已提交开业申报
- 已确认经营的商品是否需要日本国内许可（古物商许可、酒类销售业许可等）
- 已确认商品不属于外汇法的清单管制和全面管制
- 已确认商品不属于其他法令（植物防疫法、家畜传染病预防法等）的管制
- 已确认商品不属于国际邮件禁寄物品和销售国的禁止进口物品
- 已决定价值超过20万日元订单的出口申报方式（自行申报或委托报关行）
- 已决定将出口免税文件保存7年的方法
- 已准备好特定商取引法的标示，以及销售国语言的用户协议和隐私政策
- 已考虑在销售国申请商标

## 常见问题（FAQ）

**Q. 开始做跨境电商需要许可吗？**

A. 是否需要许可取决于经营的商品。收购二手商品再销售需要古物商许可，销售酒类需要酒类销售业许可，属于外汇法或其他法令管制的商品需要出口许可或批准。即使经营全新的杂货等商品，也应先确认商品不属于管制对象再开始销售。

**Q. 通过邮政向海外寄送小额商品时，需要办理出口申报吗？**

A. 价值在20万日元以下的邮件，无需向海关办理出口申报。通过日本邮政的"国际邮件My Page服务"制作海关申报单并贴在邮件上寄出即可。超过20万日元时，需要准备发票等文件办理出口申报。

**Q. 个人也可以做跨境电商吗？**

A. 可以，个人也可以做跨境电商。以个体经营者身份开始时，需要向税务署提交开业申报。商品所需的许可以及出口、寄送手续，与企业一样需要确认。

**Q. 向海外销售二手商品需要古物商许可吗？**

A. 收购二手商品再销售时，需要古物商许可。只是出售自己用过的物品，或为自用而购买但未使用的物品，不需要许可。如果难以判断，请向管辖主要营业所的警察署咨询。

## 总结与思考

跨境电商所需的文件和许可，可以分为"经营商品所需的国内许可""出口许可""寄送文件""网店的标示与法律"4项来确认。需要什么，取决于商品、目的地和寄送方式的组合，而不是"跨境电商"这种销售方式本身。

把这4项放在一起看就会发现，跨境电商新增的确认事项大多集中在"寄往海外"和"在网店销售"这两个环节。换句话说，一开始就把销售国家和商品范围缩小，需要确认的法律和文件也会随之减少。先从1个国家、少量商品开始完成确认，需要判断的部分向海关或专业人士咨询，是安心开展跨境电商的捷径。完整的上线流程，也请参阅《[跨境电商怎么做？新手入门流程与准备事项](/zh-hans/ec-guide/cross-border/cross-border-ec-how-to-start/)》。
