## 【一分钟速览】Mercari Shops只需国内发货即可卖到海外

Mercari Shops的跨境销售，是指由Mercari或与Mercari官方合作的跨境电商企业代替海外买家购买商品，并负责出口、通关和国际配送的机制。卖家只需像处理日本国内订单一样，把商品寄到指定的日本国内地址，就能完成海外销售。

手续费与国内销售相同，跨境订单不会额外收取费用（截至2026年11月）。Mercari Shops的销售手续费为含税价格的10%，销售款提现手续费为每次200日元，开店费和月费均免费。

另一方面，与海外买家的沟通由Mercari或合作企业负责，因此这一机制并不能让卖家与海外顾客建立直接联系。本文基于官方信息，梳理其运作机制、手续费和设置方法，并解析与通过自建独立站开展海外销售的区别。

## Mercari Shops跨境销售的运作机制

在Mercari Shops的跨境销售中，卖家并不直接与海外买家交易，而是由中间方以"国内买家"的身份购买商品。根据Mercari Shops官网的说明，与海外买家的沟通、发货、出口及通关等手续均由跨境电商合作企业或Mercari负责，卖家无需做任何特别处理。

### 交易流程

Mercari Shops官方文章和Mercari帮助中心介绍的流程如下：

1. 海外买家通过跨境电商企业的网站或Mercari的App下单
2. 跨境电商企业或Mercari官方账号向卖家购买商品
3. 卖家用普通包装，把商品寄到指定的日本国内地址
4. 跨境电商企业或Mercari收货后，再发往海外买家

由于收货地址在日本国内，卖家无需准备出口包装或出口单据。Mercari帮助中心还提示，即使同一买家购买了多件商品，为避免混淆，也应按每笔交易分别发货，不要合并包装。

### 海外买家购买的两种渠道

海外买家购买Mercari Shops商品的渠道主要有两种：

- **官方合作的跨境电商企业**：合作企业接收无法使用Mercari的海外买家的订单，并代为购买。Mercari Shops于2023年引入了这一机制。Mercari帮助中心列出了54家官方合作的跨境电商企业（截至2026年11月）
- **Mercari全球App（メルカリ グローバルアプリ）**：Mercari首款全球通用App，海外买家可以浏览和购买日本"Mercari"与"Mercari Shops"上的商品。2025年9月30日在台湾和香港上线，2026年6月17日（美国时间）在美国上线

根据Mercari的新闻稿，Mercari Shops卖家无需进行任何设置或申请，即可通过全球App向海外买家销售。支付与Stripe合作，配送与佐川急便等合作伙伴合作，App还支持AI实时翻译。Mercari在美国上线时的发布中还介绍了发货前由Mercari检查所有商品的"全品检验"，以及针对运输途中破损、丢失的免费赔付。

### 可销售的国家和热销品类

根据Mercari Shops官网，跨境销售已覆盖120个国家和地区，销量前三的目的地为中国大陆、美国和台湾（截至2026年11月）。同一页面还显示，2025年4月至2026年4月的跨境销售交易总额同比增长了2倍。

Mercari Shops官方文章列出的海外订单较多的品类为"玩具・爱好・周边""时尚服饰""图书・杂志・漫画"。

## Mercari Shops跨境销售的手续费

Mercari Shops跨境销售的手续费与国内销售相同。Mercari Shops官方文章明确表示，跨境订单不会另外产生运费或手续费。

| 费用 | 金额（截至2026年11月） |
|---|---|
| 开店费 | 免费 |
| 月费 | 免费 |
| 销售手续费 | 含税价格的10%（运费另计出售时，按商品价格与运费合计的10%收取） |
| 提现手续费 | 每次提现200日元 |
| 跨境订单附加费 | 无 |
| 国际运费・出口手续 | 卖家无需承担（由跨境电商企业或Mercari负责） |

卖家承担的运费，仅为寄到日本国内指定地址的运费。海外买家支付的国际运费或服务费由跨境电商企业或Mercari一方处理，与卖家的销售手续费无关。

### 手续费试算示例

根据公开的收费标准，一个月的手续费试算如下：

- 条件：单价3,000日元（含税、含运费）的商品，一个月卖给海外买家20件
- 销售额：3,000日元 × 20件 = 60,000日元
- 销售手续费：60,000日元 × 10% = 6,000日元
- 提现手续费：200日元（按每月提现1次计算）
- 卖家到手金额：53,800日元（还需扣除寄往国内指定地址的运费和商品成本）

由于没有固定费用，没有销售的月份费用为0。对于想用少量商品试探海外反应的卖家来说，这是一种门槛较低的收费方式。

## 如何在Mercari Shops开始跨境销售

在Mercari Shops开始跨境销售，只需在店铺后台将"是否接受跨境电商企业的订单"设置为"接受"即可。根据Mercari Shops官方文章，这一设置的初始状态即为"接受"。

1. 在Mercari Shops开设店铺
2. 在店铺后台点击"设置"，打开"编辑店铺信息"
3. 在"跨境电商企业订单受理"一项中选择"接受"
4. 上架商品并开始销售

如不希望开展跨境销售，在同一项中选择"不接受"即可（菜单名称为日文后台的中文译名）。

### 取消、退货与可销售的商品

Mercari Shops官方文章对取消和退货的处理说明如下：

- **取消**：海外买家通过跨境电商企业提出申请，按与国内交易相同的方式处理
- **退货**：海外买家把商品退回跨境电商企业，再由跨境电商企业退给卖家
- **丢失・破损・纠纷**：首先由跨境电商企业作为对接窗口

可销售的商品仅限于在日本国内可合法销售、且符合Mercari指南规定的商品。指南中禁止销售的商品，在跨境销售中同样不能销售。

## Mercari Shops与自建独立站出海的区别

Mercari Shops跨境销售与自建独立站海外销售最大的区别，在于能否与海外顾客直接建立联系。Mercari Shops可以把与海外买家的沟通和发货交给Mercari或跨境电商企业，但它并不是让卖家掌握海外顾客信息、建立复购关系的机制。自建独立站则需要自己搭建支付、物流和多语言体系，但可以自主打造品牌形象，并与海外顾客建立关系。

|---|---|---|
| 费用 | 开店费、月费免费 | 免费版0日元，入门版每月9,800日元（不含税）等 |
| 手续费 | 销售手续费10%，提现手续费每次200日元 | 销售额的6%（含信用卡支付手续费） |
| 多语言 | 由面向买家的网站或App处理（全球App支持AI翻译），卖家页面仍为日文 | 可搭建多语言网店（语言数量因套餐而异） |
| 多币种・支付 | 由跨境电商企业或Mercari处理 | 美元、欧元、日元；信用卡（Visa、Mastercard） |
| 国际配送・通关 | 由跨境电商企业或Mercari负责 | 卖家自行安排 |
| 获客功能 | 展示给Mercari App和跨境电商企业网站的用户；有优惠券等促销功能 | 多语言博客自动生成（SEO/AIO）、CRM、多语言邮件营销 |
| 与海外顾客的关系 | 不与海外买家直接沟通 | 顾客信息由卖家自行管理 |
| BtoB对应 | 官方信息中未能确认 | BtoB专用购物车（按企业设定价格、询价、账单支付） |

### 如何选择

选择哪种方式，取决于您希望通过海外销售实现什么目标：

- **只想通过国内发货把现有库存也卖到海外**：适合Mercari Shops跨境销售。只需修改一处设置，没有固定费用，适合作为试探海外需求的第一步
- **希望以自有品牌积累海外顾客**：适合自建独立站。如果希望通过海外SEO和邮件营销与顾客建立关系，可以选择像连获客都能交给AI的跨境电商工具Leap这样，从建站到海外获客都能一站式推进的工具

也可以两者结合：先通过Mercari Shops了解哪些商品有海外需求，再把这些商品放到自建独立站上正式销售。

## 常见问题（FAQ）

**Q. Mercari Shops的跨境销售需要额外支付手续费吗？**

A. 不需要。跨境订单与国内订单一样，只收取10%的销售手续费和200日元的提现手续费，Mercari Shops官方文章明确表示不会另外产生运费或手续费（截至2026年11月）。

**Q. 需要自己发货到海外吗？**

A. 不需要。卖家只需寄到指定的日本国内地址，国际配送、出口和通关手续均由跨境电商企业或Mercari负责。

**Q. 需要用英语等外语沟通吗？**

A. 不需要。与海外买家的沟通由跨境电商企业或Mercari负责，Mercari帮助中心也说明，卖家可以用日语与官方账号联系。

**Q. 可以关闭跨境销售吗？**

A. 可以。在店铺后台点击"设置"，打开"编辑店铺信息"，在"跨境电商企业订单受理"一项中选择"不接受"即可。

## 总结与思考

Mercari Shops的跨境销售，让卖家以与国内相同的发货方式和手续费，把商品卖给120个国家和地区的买家。随着全球App的推广，海外买家直接购买Mercari Shops商品的机会也在增加。

不过，跨境销售带来的是"在海外卖出商品的机会"，而不是"与海外顾客的关系"。由于与买家的沟通由中间方负责，卖家很难了解是谁购买了商品，也难以让顾客再次回购。先通过Mercari Shops验证海外需求，再把反响好的商品逐步拓展到自有的顾客经营中，按照这样的顺序思考，就能自然地发挥两种渠道各自的优势。
