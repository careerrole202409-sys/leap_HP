## 【一分钟速览】容易被忽视的一条获客渠道

经营BASE店铺时，很容易把注意力都放在Google搜索和社交媒体引流上，却忽略了BASE自身独有的一条强大获客渠道——面向购物者的专用App"PAY ID"（原"BASE App"）。如果不了解自家店铺在PAY ID内是如何被搜索、被发现的，就等于白白错过了这个BASE独有的获客机会。本文将解析PAY ID App内的搜索机制、提升搜索曝光度的设置方法，以及如何通过增加粉丝、善用推送通知来提升经由PAY ID带来的销量。

## PAY ID App是什么

PAY ID是面向购物者的专用手机App，用户可以在其中浏览并购买通过BASE搭建的店铺所售卖的商品。任何在BASE开店的商家，只需在管理后台将"上架至PAY ID"的开关打开，即可免费将自家店铺同步展示在PAY ID内。这条渠道的最大优势在于，它能让商家绕开自家官网或社交媒体，直接触达BASE购物者这一独立社群。

需要注意的是，免费的仅是"上架展示"本身。一旦通过PAY ID产生实际订单，仍会按照与普通BASE简易支付相同的标准收取结算手续费（3.6%+40日元）与服务使用费（5.9%）。上架本身无需初期费用或月费，但这并不意味着销售环节的手续费也一并免除。

## 提升搜索曝光度的关键设置

店铺在PAY ID内是否容易被发现，取决于几项基础设置。

首先是店铺描述文案。认真撰写店铺描述，据称有助于让店铺更容易出现在搜索结果中。关键在于清晰传达店铺经营的商品类型、目标顾客群体，并自然地融入相关关键词。

其次是店铺Logo的设置。设置Logo不仅有助于在搜索结果和商品列表中脱颖而出，还能提升顾客的信任感。相比只有商品图片的店铺，配有完整Logo的店铺往往更容易让首次访问的顾客产生安心感。

还有一项容易被忽视的设置是"店铺分类"。BASE官方指出，设置准确的店铺分类有助于提升在PAY ID内的搜索曝光度。建议选择与自家经营商品最贴近的分类，不要让这一项处于未设置状态。

商品展示顺序同样值得关注。在PAY ID App中，店铺首页第一屏最多只能显示3件商品。也就是说，是否把畅销商品或主打商品放在最前面，会直接影响首次访问顾客的第一印象。建议养成定期检视商品排序的习惯，确认当下最想主推的商品是否位列前三。

商品标题与描述文案的完善程度也不容忽视。借助BASE的AI助手功能，可以更高效地撰写简洁清晰的商品描述，即便没有太多时间投入文案创作的商家，也能高效整理商品信息。

## 增加粉丝的好处与推送通知的活用方法

PAY ID设有店铺"关注"功能。粉丝数量较多的店铺，往往更容易出现在App首页的推荐位置，从而增加接触新顾客的机会。想要增加粉丝，一个有效方法是在Instagram等社交媒体的个人主页中附上PAY ID店铺链接。此外，系统还设有自动关注机制：当顾客通过店铺的PAY ID链接安装App并首次启动后，会自动关注该店铺，因此有意识地为外部渠道设计导向PAY ID的入口，也十分重要。

积累一定粉丝基础后，接下来值得善用的就是推送通知。只要店铺在PAY ID上已有粉丝，只需在管理后台登记新商品，系统就会自动向粉丝推送通知。手动发送推送通知本身完全免费，且单日发送次数不限，新建推送时可以选择"商品推广""店铺推广""优惠券发放"等不同用途的模板。此外，BASE还提供AI功能，可自动生成推送通知文案，但目前仅支持"商品推广"与"店铺推广"这两类，"优惠券发放"暂不支持AI自动生成，仍需商家自行撰写文案。

需要区分开的是，BASE还提供了一项针对"已将商品加入购物车却未完成购买"顾客的免费提醒邮件功能——"防止忘记购买提醒邮件"。但这项功能仅针对通过Web店铺完成的购物行为，**通过PAY ID App产生的购买不在该提醒邮件的覆盖范围内**。也就是说，想要触达在PAY ID内产生"加购未下单"行为的顾客，主要依靠的还是面向粉丝的推送通知，而非这项提醒邮件功能。

## 常见问题（FAQ）

**Q. 上架到PAY ID App需要付费吗？**

A. 上架本身免费，只需在管理后台将"上架至PAY ID"的开关打开即可，不会产生额外的初期费用或月费。不过，一旦通过PAY ID产生实际订单，仍会按普通BASE简易支付的标准收取结算手续费与服务使用费。

**Q. 怎样才能增加粉丝？**

A. 在Instagram等社交媒体的个人主页中附上PAY ID店铺链接是一种有效方法。此外，系统还设有自动关注机制：顾客通过该链接安装App并首次启动后会自动关注店铺，因此有意识地设计从外部渠道导向PAY ID的入口非常重要。

**Q. 推送通知发太多会不会引起顾客反感？**

A. 发送本身免费且不限次数，但发送频率过高可能导致粉丝取消关注。建议将推送通知集中用于新品上架、促销开始等对顾客确实有价值的时机。

## 总结与思考

PAY ID App内的获客，与Google搜索优化或社交媒体运营完全是两套逻辑。仅仅完善店铺描述文案、Logo、商品展示顺序等基础设置，就能显著改变店铺被发现的难易程度；而善用粉丝与推送通知机制，则能在不增加成本的前提下，持续与顾客保持联系。能否用好这条只有选择BASE这一平台才能获得的应用内获客渠道，或许正是决定店铺经营成果的一个隐藏关键点。
