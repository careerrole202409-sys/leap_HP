## 1. ポジショニング

- 呼び方：**集客までAIに任せられる越境ECツール**（rules.md 1-1。言い換えない）
- ひとことで：越境ECサイトの制作から、海外集客、日々の管理までを、AIがチャットで実行するツール
- これまで別々に依頼していた「制作・集客・運用」を、ひとつのチャットで進められる
- 他のツールとの違い（Leapの立ち位置）
  - 多くのECツールは「サイトの制作・管理」まで。Leapは「海外集客の実行」までAIが行う
  - 大企業向けの複雑なツールではなく、シンプルな使い勝手（チャットで話しかけるだけ）
- 外注との比較（記事で使う場合は、出典の記事を自分で確かめてから使う）
  - サイト制作・多言語化・集客・メルマガ・EC運用をすべて個別に外注すると、月100万円を超える試算になる（Leap紹介資料。業務委託・代行の一般的な相場をもとにした試算）

## 2. 実装済みの機能

### 2-1. 制作
| 機能 | 中身 |
|---|---|
| 越境EC・グローバルサイト・海外向けLPの作成 | ヒアリングのチャットに答え、デザインテンプレートから選ぶだけで作成できる |
| AIチャットでのデザイン編集 | 変えたい要素をクリックし、チャットで伝えるだけで、公開中のサイトを編集できる |

### 2-2. 集客
| 機能 | 中身 |
|---|---|
| ローカライズの提案と自動修正 | 言語と進出国を選ぶと、AIがローカライズの提案を出し、そのまま修正できる |
| 多言語ブログの自動作成（SEO/AIO） | 読者ターゲットなどをチャットで聞き取り、タイトルから本文まで、AIが記事を構成・作成する |
| CRM（顧客管理） | 顧客情報を一元管理。CSVでの取り込みに対応 |
| 多言語メルマガ配信 | チャットで指示するだけで配信できる |
| アクセス解析 | HPのアクセス状況を可視化。国ごとのアクセス数を見られるので、国別のテストマーケティング（市場調査）に使える |

### 2-3. 管理
| 機能 | 中身 |
|---|---|
| 商品管理 | 商品の追加・編集・在庫管理をチャットとフォームで行える。CSVでの取り込みに対応。国別の価格設定・多通貨に対応。BtoB向けには、まず見積もり依頼として受け付けることもできる |
| 注文管理 | 注文状況の確認、発送・キャンセル対応をチャットで相談しながら行える。期間別（7日・30日・90日）の売上推移、ステータス（未対応・対応中・発送済み・キャンセル）での絞り込み |
| お問い合わせ管理 | フォームからの問い合わせを一覧で管理。返信文の作成をAIチャットに任せられる |

### 2-4. 越境ECの仕様（2026年11月時点）
| 項目 | 中身 |
|---|---|
| 決済手段 | クレジットカード（Visa・Mastercard）。BtoB専用ECでは銀行振込・請求書払いにも対応 |
| 手数料 | 売上の6%（クレジットカード決済手数料を含む） |
| 対応国（主要22カ国） | 北米・南米（4）：アメリカ、カナダ、メキシコ、ブラジル／ヨーロッパ（6）：イギリス、ドイツ、フランス、イタリア、スペイン、オランダ／アジア・オセアニア（12）：日本、オーストラリア、シンガポール、中国本土、台湾、香港、韓国、ベトナム、フィリピン、マレーシア、インドネシア、インド |
| 対応通貨 | 米ドル・ユーロ・日本円 |
| 国ごとの商品設定 | 商品ごとに販売国を設定できる。それ以外の国では商品が表示されない |
| 為替 | 商品ごとに基軸通貨を1つ選ぶと、前日の為替レートで自動換算し、ほかの通貨でも毎日自動で表示する |

### 2-5. BtoB専用カート
| 項目 | 中身 |
|---|---|
| 会員・ログイン | ログイン機能。定価をデフォルトで表示 |
| 価格設定 | 企業ごとに価格を変更できる。数量による値引きを自動で設定できる |
| 見積・注文 | 見積もり依頼。注文データのCSV出力 |
| 商品情報 | 入数・重量などの商品情報を登録できる |
| 決済 | 銀行振込・請求書払い |
| 越境対応 | 多言語・多通貨、国ごとの商品表示 |

- Leapが劣る項目（カスタマイズ性、BtoB専用カートの機能の幅）も、記事では正直に書く

### 4-2. 「〜ならLeap」（おすすめを条件付きで書くときに使う）
- 海外集客（SEO・メルマガ・ローカライズ）まで、まとめてAIに任せたいならLeap
- 専門知識や、制作・運用の人手がないならLeap（チャットで話しかけるだけ）
- 翻訳だけでなく、進出国に合わせたローカライズまでしたいならLeap
- BtoBで、まずは海外バイヤーの募集から小さく始めたいならLeap（バイヤー募集LP → 集客 → 問い合わせ）

### 4-3. Leap以外が向いているケース（公平に書くために使う）
- デザインや機能を細かくカスタマイズしたい、アプリで機能を大きく拡張したい → Shopifyなど
- 国内向けに、無料で手軽にネットショップを始めたい → BASE・STORESなど
