Frequently Asked Questions (FAQ)

How accurate is the translation?
Leap uses the latest AI technology and is equipped with an AI double-check (refinement) function. This achieves natural, native-quality expressions that fit the context, rather than literal translations.
What happens if the original Japanese site changes?
It detects updates to the original site and automatically translates and reflects only the differences. It is possible to keep the multilingual versions constantly up to date.
Can I use a custom domain?
Yes, by using the paid plan (Standard), you can set up your own custom domain (e.g., en.yourcompany.com). The free plan uses a Leap subdomain.
Can you tell me more about the pricing structure?
You can use the Free Plan forever if you only need 1 language. For the second language onwards, or if using a custom domain, a fee of 20,000 JPY (excluding tax) per added language applies.
